# ThoughtSpot MongoDB Atlas + Voyage Retrieval POV - backend

Generated by the poc-builder **backend coding agent** from the POV contracts
(`api_contract`, `data_model`, `query_patterns`, `requirements`). Stack: Python 3.11, FastAPI,
Pydantic v2, PyMongo Async API.

## Run

```bash
cp env.example .env           # set MONGODB_URI and MONGODB_DATABASE
uv sync --frozen
uv run python -m app.db.indexes --wait   # unique, query and vector-search indexes
uv run uvicorn app.main:app --host 127.0.0.1 --port 8080
curl http://127.0.0.1:8080/api/health
```

## Test

```bash
uv run ruff check . && uv run pyright
uv run pytest tests/contract tests/db tests/services   # no database needed
BE_TEST_MONGODB_URI=... uv run pytest tests/integration # real MongoDB/Atlas (optional)
```

## Layout

- `app/api/routes`, `app/api/schemas.py`, `app/errors.py`, `app/db/*`, `app/models/*` - generated, read-only.
- `app/services/*` - business logic (method signatures are fixed by the contract).
- `component.manifest.json` - install/build/bootstrap/start/healthcheck for the deploy agent.
- `openapi.json` - exported from the verified build. Location in repo: `backend_code`.
